03 / CASE STUDY · Digital accessibility

ClariVoz

An assistive technology prototype with text-to-speech, demonstrative text simplification and accessibility controls.

Open prototype ↗View code on GitHub ↗
Public prototypeNext.js 16React 19TypeScriptTailwind CSS 4
01 / Context

The problem behind the project

Digital information can be difficult for different people to read or understand. ClariVoz explores how a simple interface can offer tools to adapt the reading experience.

02 / Product

What I built

Text-to-speechRead text aloud using the browser's built-in speech capabilities.
Demonstrative simplificationAn example of presenting text in more accessible language.
Visual controlsAdjust text size and contrast to suit different reading preferences.
Accessible navigationA responsive interface designed with keyboard navigation in mind.
03 / Workflow

How the solution works

  1. 01
    Enter contentThe user opens the prototype and provides the text they want to work with.
  2. 02
    Choose a featureTry text-to-speech or the demonstrative simplification feature.
  3. 03
    Adjust the experienceUse the visual controls according to individual needs.
04 / Engineering

What the code demonstrates

The project combines Next.js, React and TypeScript. Text-to-speech uses the Web Speech API, while the interface offers responsive presentation and navigation features. The repository includes screenshots of the prototype.

05 / Transparency

Current stage and limitations

This is a demonstration prototype. Speech playback depends on browser support, and the simplification feature should not be presented as professionally validated accessibility guidance.

Credits and contributions. A project published in Geovanna Eduarda da Silva's GitHub account, with a publicly accessible prototype.
