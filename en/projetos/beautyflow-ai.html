02 / CASE STUDY · Python, APIs and digital products

BeautyFlow AI

A prototype for managing appointments, clients and services in beauty businesses, with an API and demonstration automation features.

View public presentation ↗View code on GitHub ↗
Local MVPPythonFastAPIStreamlitSQLModel
01 / Context

The problem behind the project

Small beauty businesses often manage appointments, client records and customer service across spreadsheets, messages and notes. BeautyFlow was created to bring these routines together in a demonstration application.

02 / Product

What I built

Daily operationsManage clients and services, schedule appointments and update booking statuses.
Business indicatorsA dashboard with demonstration data for appointments, revenue and average ticket value.
Recommendations and campaignsService suggestions and support for drafting customer messages.
API and testingFastAPI endpoints, automatically generated documentation and tests for core workflows.
03 / Workflow

How the solution works

  1. 01
    InterfaceStreamlit provides pages for viewing indicators and managing day-to-day tasks.
  2. 02
    APIFastAPI handles operations, validates data and organizes business rules.
  3. 03
    PersistenceDemonstration data is stored in SQLite using SQLModel models.
04 / Engineering

What the code demonstrates

Separating the Streamlit interface, FastAPI backend and SQLite database makes it possible to explore the full workflow of a Python application. The repository includes Pytest and HTTPX tests, sample data and configuration instructions.

05 / Transparency

Current stage and limitations

This MVP is not ready for real customer data. The login is demonstrative rather than secure, WhatsApp functionality is simulated, and the assistant uses an LLM only when an API key is configured. Secure deployment, multi-user authentication and official WhatsApp integration remain future work.

Credits and contributions. An individual project by Geovanna Eduarda da Silva. The current version is available to run locally using the repository instructions.
