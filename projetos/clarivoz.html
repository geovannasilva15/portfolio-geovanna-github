03 / ESTUDO DE CASO · Acessibilidade digital

ClariVoz

Uma experiência de tecnologia assistiva com leitura em voz alta, simplificação demonstrativa e controles de acessibilidade.

Abrir demonstração ↗Ver código no GitHub ↗
Protótipo públicoNext.js 16React 19TypeScriptTailwind CSS 4
01 / Contexto

O problema que motivou o projeto

Informações digitais podem ser difíceis de ler ou compreender para diferentes pessoas. O ClariVoz explora como uma interface simples pode oferecer recursos para adaptar a experiência de leitura.

02 / Produto

O que foi construído

Leitura em voz altaReprodução de texto utilizando os recursos de voz do navegador.
Simplificação demonstrativaExemplo de apresentação de textos em linguagem mais acessível.
Controles visuaisAjustes de tamanho e contraste para diferentes preferências de leitura.
Navegação acessívelInterface responsiva com atenção à utilização pelo teclado.
03 / Funcionamento

Como a solução funciona

  1. 01
    Inserir conteúdoA pessoa acessa o protótipo e informa o texto com que deseja trabalhar.
  2. 02
    Escolher recursoPode experimentar a leitura em voz alta ou a simplificação demonstrativa.
  3. 03
    Ajustar a experiênciaUtiliza os controles visuais conforme sua necessidade.
04 / Engenharia

O que o código demonstra

O projeto combina Next.js, React e TypeScript. A leitura em voz alta utiliza a Web Speech API, enquanto a interface oferece recursos de apresentação e navegação responsiva. O repositório contém capturas das telas.

05 / Transparência

Estágio atual e limites

Trata-se de um protótipo demonstrativo. O funcionamento da narração depende do suporte do navegador e os recursos de simplificação não devem ser apresentados como validação especializada de acessibilidade.

Autoria e participação. Projeto publicado no GitHub de Geovanna Eduarda da Silva, com protótipo acessível por link público.
