02 / ESTUDO DE CASO · Python, APIs e produto digital

BeautyFlow AI

Uma plataforma para organizar agenda, clientes e serviços de negócios de beleza, com API e recursos demonstrativos de automação.

Ver página pública ↗Ver código no GitHub ↗
MVP localPythonFastAPIStreamlitSQLModel
01 / Contexto

O problema que motivou o projeto

Pequenos negócios de beleza frequentemente distribuem agendamentos, cadastros e atendimento entre planilhas, mensagens e anotações. O BeautyFlow foi criado para reunir essas rotinas em uma aplicação demonstrativa.

02 / Produto

O que foi construído

Gestão do dia a diaCadastro de clientes e serviços, agenda e atualização de status de atendimentos.
IndicadoresPainel com dados demonstrativos de agenda, receita e ticket médio.
Recomendações e campanhasSugestões de serviços e apoio à criação de mensagens para clientes.
API e testesEndpoints em FastAPI, documentação automática e testes de fluxos principais.
03 / Funcionamento

Como a solução funciona

  1. 01
    InterfaceO Streamlit apresenta páginas para visualizar indicadores e executar tarefas de gestão.
  2. 02
    APIO FastAPI recebe as operações, valida dados e organiza as regras de negócio.
  3. 03
    PersistênciaOs dados de demonstração são armazenados em SQLite, com modelos SQLModel.
04 / Engenharia

O que o código demonstra

A separação entre interface Streamlit, API FastAPI e banco SQLite permite estudar o funcionamento completo de uma aplicação Python. O repositório inclui testes com Pytest e HTTPX, dados de demonstração e documentação de configuração.

05 / Transparência

Estágio atual e limites

O MVP não está pronto para uso com dados reais. O login é demonstrativo e não oferece autenticação segura; o WhatsApp é simulado; e o assistente usa LLM somente quando uma chave de API está configurada. Publicação segura, autenticação multiusuário e integração oficial com WhatsApp ainda fazem parte do roadmap.

Autoria e participação. Projeto autoral de Geovanna Eduarda da Silva. A versão atual está disponível para execução local, com instruções no repositório.
